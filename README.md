# SRVFORGE — подбор серверов и ПК

Статический сайт-конфигуратор: готовые сборки под задачи и бюджет, конструктор с проверкой совместимости, каталог комплектующих, тесты и разбор «что лучше брать».

## Что внутри
- **Подбор** — 11 сценариев (7 серверных, 4 ПК) × 3 уровня. Ползунок бюджета подсвечивает подходящую сборку, показывает «картину бюджета» и советы.
- **Конструктор** — 20+ проверок: сокет, тип памяти (DDR5 / ECC UDIMM / RDIMM), слоты и каналы памяти, форм-фактор, мощность БП, высота кулера в 1U/2U, пассивные GPU, отсеки под диски, U.2.
- **Каталог** — 120+ позиций: Ryzen/Core Ultra, Threadripper, EPYC 4005/8004/9005, Xeon 6, RTX 50 / Radeon 9000 / RTX PRO / L4 / L40S / H200, RDIMM, enterprise NVMe, HDD, шасси.
- **Тесты** — рейтинги GPU/CPU, режим «за каждые $100», цена ГБ памяти и ТБ дисков.
- Валюты USD / BYN / RUB с настраиваемым курсом.

## Запуск
Открыть `index.html` в браузере — сборка не нужна. Для GitHub Pages: Settings → Pages → Deploy from branch → `main` / root.

## Данные
Все комплектующие и сборки — в `js/data.js`. Цены — ориентир на ноябрь 2026 (розница США/ЕС), индексы производительности — сводные оценки по публичным обзорам.
